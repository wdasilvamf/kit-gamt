# Do sonho ao primeiro degrau · Kit GAMT

Kit de continuidade do encontro **"IA no mercado de trabalho"** do projeto social GAMT, para jovens de 16 a 19 anos.

São cinco missões curtas no celular, feitas com qualquer IA gratuita. No fim, cada participante tem a escada da profissão dos sonhos, uma vaga real como primeiro degrau e um plano de 3 meses revisado por uma pessoa de verdade.

**Acesse:** https://SEU-USUARIO.github.io/kit-gamt/

## Para quem participa

1. Abra o link no Chrome ou no Safari (dentro do Instagram ou do WhatsApp, algumas funções não funcionam).
2. Preencha os campos de cada missão, copie o pedido e cole no chat de uma IA (ChatGPT, Gemini, Claude ou Copilot).
3. Confira a resposta, anote com as suas palavras e carimbe a missão.
4. No fim, baixe o seu mapa. **O que você escreve fica salvo só neste celular**: trocar de aparelho ou limpar os dados apaga tudo.

Para usar como app: no Android, toque em "Instalar como app no celular". No iPhone, use Compartilhar e depois "Adicionar à Tela de Início". Depois da primeira visita, funciona sem internet.

## Para quem conduz a turma

O guia do facilitador fica no endereço do kit + `#facilitador`. Ele traz a dinâmica em duplas, a divisão entre o que fazer em sala e em casa, e as mensagens prontas para o grupo no dia 7 e no dia 30.

## Privacidade

A página não tem cadastro nem servidor de dados. Nada é enviado para ninguém. As respostas ficam no navegador de cada pessoa. A orientação em todas as missões é não colar CPF, endereço, telefone ou senhas na IA.

## Manutenção

**Publicar (primeira vez):** Settings → Pages → Branch `main`, pasta `/ (root)` → Save. O endereço aparece em 1 a 2 minutos.

**Atualizar:** Add file → Upload files, arraste os arquivos que mudaram. Se mudou o `index.html`, abra o `sw.js` e troque `primeiro-degrau-v1` por `v2`, `v3`... para os celulares pegarem a versão nova.

| Arquivo | Função |
|---|---|
| `index.html` | A página inteira |
| `wbot.webp`, `wbot-cabeca.webp` | Ilustrações do Wbot |
| `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` | Nome e ícone do app |
| `sw.js` | Funcionamento offline |

Os limites das ferramentas de IA citadas foram conferidos em novembro de 2026 e mudam com frequência.
